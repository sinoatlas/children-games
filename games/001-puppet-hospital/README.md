# 玩偶小医院·苏教生物与图画版

游戏编号：`001-puppet-hospital` · 版本：1.1 · 3岁妹妹、初一哥哥与父母 · 一位玩偶8至12分钟

[下载完整原套装 ZIP](../../downloads/001-puppet-hospital/玩偶小医院苏教生物图画版.zip?raw=true) · [返回游戏总目录](../../README.md)

## 直接开始玩

1. 阅读[规则书](printable/规则书.pdf)第2页。
2. [打印材料](printable/打印材料.pdf)先印第 **1、3、6、8、10、13、14、17、18页**，共9页，A4、100%、单面。
3. 小熊＋S1细胞证件；家长留线索卡，妹妹选照顾办法，哥哥每局最多加一张生物任务。

规则书10页，打印材料18页。图卡建议彩色，由成人剪裁。完整首局台词与其他玩法都在规则书里。

## 内容放在哪里

| 目录 | 用途 |
|---|---|
| `printable/` | 可以直接打印的规则书与全套材料PDF |
| `editable/` | 可修改规则、卡片文字与结构化数据 |
| `assets/` | 完整插画原图 |
| `src/` | PDF生成脚本 |
| `references/` | 核对来源、插画提示词与原套装说明 |
| `game.json` | 编号、版本、适用对象、页码与生成配置 |

下载ZIP保留此前完整套装的文件名和结构；仓库内按用途分类，内容相同。修改Markdown不会自动更新PDF。需要重新生成时，在仓库根目录运行：

```powershell
python scripts/build_game.py 001-puppet-hospital
```

编辑来源：[资料来源](references/资料来源.md) · [插画提示词](references/图画提示词.md)。插画使用内置ImageGen生成。文件已核对排版；此版尚未实际家庭试玩，可以按孩子的兴趣调整。
